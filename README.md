## Hey there, I'm sainthoodzo 👋

I'm a backend engineer who spends most of his time building APIs in Go and Python, usually with FastAPI on the Python side and PostgreSQL holding everything together underneath. I think a lot about how services talk to each other — the boundaries, the failure modes, the parts where a clean interface saves you from a mess six months later. Lately I've been drawn deeper into distributed systems and the small design choices in databases and caching layers (Redis, mostly) that end up mattering more than you'd expect.
